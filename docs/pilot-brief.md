# Pilot Brief

## Research objective

SÆNTRA / TFL-UAS

Primary research question:

Can relational-state methods derived from TFL/RIC extract more robust or more informative structure from noisy, incomplete, distributed observations of moving objects than conventional tracking and sensor-fusion methods?

Secondary research question:

Can TFL/RIC distinguish organized coordinated multi-object behavior from mere spatial proximity more reliably than conventional point-track approaches?

The research program is strictly falsification-oriented.

The first completed experiment, TFL-UAS-001A, tested point → track and returned NO-GO for the RIC candidate.

The next experiment, TFL-UAS-001B, will therefore test relation → organization using established tracks so that tracking quality does not confound organization detection.

## Scope exclusions

The current phase is strictly synthetic and excludes:

- BAE
- SCOPE
- OASE
- HOSIP
- real imagery
- cellular subscriber data
- RF protocol identification
- neural object classifiers
- external intelligence sources
